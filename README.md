🚁 **SkyRoute: An AI-based drone delivery simulation that models autonomous routing and dispatch decisions.**

For my Computational Foundations for AI coursework, I wanted to go beyond implementing individual algorithms and build a complete simulation where autonomous drones make delivery decisions under real-world constraints.

The system simulates a fleet of delivery drones navigating a city while considering battery levels, weather conditions, delivery priorities, and optimal routing—all in real time.

### Features

• A* pathfinding for efficient route planning
• Dynamic weather system affecting routing and battery usage
• Priority-based delivery scheduling for medicine, food, and shopping requests
• Battery management with autonomous charging decisions
• Eco-mode delivery merging for improved efficiency
• Live simulation dashboard built with Pygame

### How I built it

→ Designed the drone agent and delivery workflow in Python
→ Implemented the A* search algorithm for route optimization
→ Built a probabilistic weather module that influences routing decisions
→ Developed a priority queue for delivery scheduling and dispatch
→ Added battery estimation and autonomous charging logic
→ Visualized the complete simulation using Pygame

### Tech Stack

Python • Pygame

This project helped me better understand how classical AI techniques—such as informed search, constraint-based reasoning, and agent-based decision making—can work together to solve a realistic logistics problem.
